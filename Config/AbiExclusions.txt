# Types whose ARK ABI changes are intentionally NOT reproduced in the SDK headers.
#
# These are gameplay / rendering types of the Engine, RenderCore and RHI modules. ARK changed several of them
# deeply (new ARK base classes UPrimalActor, UPrimalActorComponent, UPrimalWorld, APrimalController,
# FPrimalViewportClient; renamed members used by inline engine code), which cannot be reconstructed from the
# PDBs alone. BlueprintAssist only handles them as opaque pointers (casts, StaticClass(), null checks).
#
# This is verified mechanically by Build\Tools\Test-LayoutIndependence.ps1: the plugin is compiled a second time
# with a probe data member and a probe virtual function injected at the start of every class listed here, and
# the generated machine code of all object files must be identical. Any dependency of the plugin's code on the
# layout or vtable of these types would change the code.
#
# One type name per line (as printed by PdbLayout), '#' starts a comment.
